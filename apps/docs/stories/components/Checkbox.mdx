# Checkbox

An independent on-off choice. Use a group of checkboxes when people can pick several things; use a RadioGroup when they pick exactly one.

<Controls of={CheckboxStories.Unchecked} />

## Usage notes

- The label is part of the component and part of the click target, so the whole row is pressable and at least 24px tall.
- `isIndeterminate` is for "some of the things below are selected" parent boxes.
- Keyboard: Tab reaches the checkbox, Space toggles it.
- The check mark is drawn with an icon on a filled box, so the checked state is a shape change, not only a color change.
