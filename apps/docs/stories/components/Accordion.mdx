# Accordion

A list of Disclosure rows drawn as one block: shared borders, one outline, keyboard friendly. Use
it for a list of collapsible records, like the jobs in a work history.

## Usage notes

- Give each child Disclosure an `id`; the group tracks open rows by it. `expandedKeys` and
  `onExpandedChange` control them, `defaultExpandedKeys` starts some open.
- Several rows can be open at once by default, which suits records a person works through.
  `allowsMultipleExpanded={false}` keeps one open at a time; use it only when panels are long.
- The Disclosure rules still hold: nothing a person must act on hides in a closed row unless the
  page names it in words when it blocks them.
