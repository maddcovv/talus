# Tag

A small, quiet label for a fact: a skill, a source, a location.

## Usage notes

- Tags state facts. When the color itself carries meaning (success, warning, danger), use Badge instead.
- Keep the text to a word or three. A tag is scanned, not read.
- Tags are not interactive. If removing or filtering is needed, wrap or pair them with a Button.
